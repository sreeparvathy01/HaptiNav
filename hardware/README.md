# Hardware

This directory contains the hardware design and component information for HaptiNav.

## Main Components

- ESP32 development boards × 2
- Ultrasonic sensors × 4
- Servo motors × 3 or 4, depending on the final configuration
- Headband and glove
- Power supply and connecting wires
